# سامانه هوشمند مدیریت پروژه‌ی کارشناسی مبتنی بر عامل‌های هوش مصنوعی

پروژه‌ی کارشناسی بهاران شیخ‌الاسلامی، دانشکده مهندسی کامپیوتر دانشگاه صنعتی امیرکبیر (استاد راهنما: دکتر سلیمان فلاح).

گردش‌کار ثبت، داوری و دفاع پروژه‌ی کارشناسی به‌صورت یک ماشین‌حالت در یک پورتال جنگو پیاده شده است. چهار عامل هوش مصنوعی (اعتبارسنجی سند، دستیار آیین‌نامه با RAG، تطبیق استاد برای پیشنهاد داور و استاد راهنما، و اطلاع‌رسانی) در n8n هماهنگ شده‌اند و فقط پیشنهاد می‌دهند؛ هر تصمیم را انسان می‌گیرد.

| سند | محتوا |
|---|---|
| [docs/INSTALL.md](docs/INSTALL.md) | راهنمای کامل نصب و اجرا روی مک (همراه با Ollama) |
| [docs/phase3.md](docs/phase3.md) | لایه‌ی عامل‌ها در n8n |
| [docs/phase4.md](docs/phase4.md) | یکپارچه‌سازی، سناریوهای سرتاسری و حالت سایه |
| [docs/reports/](docs/reports/) | گزارش اجرای سناریوها |

شروع سریع (پس از انجام پیش‌نیازهای INSTALL.md):

```bash
source venv/bin/activate
docker compose up -d
python manage.py migrate && python manage.py seed_demo
bash n8n/import.sh
python manage.py runserver 0.0.0.0:8000
```
